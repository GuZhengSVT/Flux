# Flux 视觉规范：简洁现代

## 设计语言

- 红、黑、白/纸色为绝对主色。
- 大量使用几何切割：斜线、矩形、圆形。
- 标题使用极粗无衬线，紧凑网格布局。
- 动效克制，滚动流畅优先。

## 颜色 Token

| Token | Light | Dark |
|-------|-------|------|
| Primary Red | `#E53935` | `#FF4C41` |
| Background | `#F7F4ED` | `#0D0D0F` |
| Surface | `#FFFFFF` | `#161619` |
| Raised Surface | `#F0ECE3` | `#202024` |
| Text | `#111111` | `#F2EFE9` |
| Muted Text | `#8A8A8E` | `#9B9B9E` |
| Border | `#1F111111` | `#29F2EFE9` |

## 组件

- 卡片圆角统一 `2px`，接近直角。
- 强调色只用于关键操作、未读标记、品牌字。
- 暗黑模式下保持高对比，图片区域使用深色表面与红色描边。
- 文章未读使用左侧红色竖条，阅读后消失。

## 字体

- 标题：`FontWeight.w800~w900`，字距略大。
- 正文：默认 16px，行高 1.5~1.7，可在设置中调节。
