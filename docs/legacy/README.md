## 1. 目的

本文件划清两件事的边界：

1. 新版 Flux 的授权范围（MIT，见仓库根目录 [LICENSE](../../LICENSE)）；
2. 旧版 Flux 的代码与素材的授权范围。

重写是从零开始的新实现，不是对旧代码的许可变更。

## 2. 授权边界

**旧版素材版权归原权利人，不因重写自动转为 MIT。**

具体含义：

- 旧版 Flux 的源代码、图标、图片、文案及其他素材，不因出现在同一仓库历史中、也不因新版采用 MIT，就自动适用 MIT。
- 旧版按封存时的原有授权条件保留。封存保留了完整的 Git 历史与标签，因此历史上每个版本当时适用的授权条件仍可追溯。
- 若某份旧素材的授权条件不清楚，或不允许再分发，则**不复制进新工程**，改为自制或寻找许可清晰的替代品（架构说明书 D-13：图标与美术素材由项目自制原创 SVG）。

新版 Flux 自己的代码与本项目自制的素材适用 MIT；第三方依赖、字体与厂商素材各自保留其原许可证。
